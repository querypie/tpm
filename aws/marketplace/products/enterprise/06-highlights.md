# Highlights

## English - AWS source

1. Enterprise governance: Unify least-privilege access, approvals, monitoring, and audit trails across databases, servers, Kubernetes, web applications, and MCP tools.
2. Browser-based workspaces: Execute SQL with Web SQL Editor, run server commands with Web Terminal, and explore Kubernetes resources with Kubernetes Web Client (beta).
3. Private offer flexibility: Purchase negotiated rights through an AWS Marketplace private offer and validate the issued `.crt` locally without an ongoing external license-service connection.

## 한국어 리뷰용 번역

1. 엔터프라이즈 거버넌스: 데이터베이스, 서버, Kubernetes, 웹 애플리케이션, MCP 도구 전반의 최소 권한 접근, 승인, 모니터링, 감사 추적을 통합합니다.
2. 브라우저 기반 작업 환경: Web SQL Editor에서 SQL을 실행하고, Web Terminal에서 서버 명령을 실행하며, Kubernetes Web Client(베타)에서 Kubernetes 리소스를 탐색합니다.
3. 유연한 Private Offer: AWS Marketplace Private Offer로 협의된 권리를 구매하고 발급된 `.crt`를 지속적인 외부 라이선스 서비스 연결 없이 로컬로 검증합니다.
