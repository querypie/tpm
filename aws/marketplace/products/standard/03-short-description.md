# Short description

## English - AWS source

QueryPie ACP Standard Edition is a self-managed access control platform for teams with 10 or more active users.
It governs databases, servers, Kubernetes, and MCP tools with policies, approvals, and audit trails, and provides a browser-based Web SQL Editor, Web Terminal, and Kubernetes Web Client (beta) from a preconfigured AMI.

## 한국어 리뷰용 번역

QueryPie ACP Standard Edition은 10명 이상의 활성 사용자를 위한 자체 운영형 접근 제어 플랫폼입니다.
데이터베이스, 서버, Kubernetes, MCP 도구에 정책, 승인, 감사 추적을 적용하며 사전 구성된 AMI에서 브라우저 기반의 Web SQL Editor, Web Terminal, Kubernetes Web Client(베타)를 제공합니다.

## 검증

영어 원문은 AWS 메타데이터 작성 가이드의 350자 이내 기준을 충족하도록 작성했습니다.
