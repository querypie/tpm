# Highlights

## English - AWS source

1. Unified policy and audit: Manage least-privilege access, approvals, monitoring, and audit trails across databases, servers, Kubernetes, and MCP tools.
2. Browser-based workspaces: Execute SQL with Web SQL Editor, run server commands with Web Terminal, and explore Kubernetes resources with Kubernetes Web Client (beta).
3. Self-managed production: Run the platform in your AWS account with licensed capacity starting at 10 active users.

## 한국어 리뷰용 번역

1. 통합 정책과 감사: 데이터베이스, 서버, Kubernetes, MCP 도구 전반의 최소 권한 접근, 승인, 모니터링, 감사 추적을 관리합니다.
2. 브라우저 기반 작업 환경: Web SQL Editor에서 SQL을 실행하고, Web Terminal에서 서버 명령을 실행하며, Kubernetes Web Client(베타)에서 Kubernetes 리소스를 탐색합니다.
3. 자체 운영 프로덕션: 10명 이상의 활성 사용자 라이선스로 구매자의 AWS 계정에서 플랫폼을 직접 운영합니다.
