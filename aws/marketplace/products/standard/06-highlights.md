# Highlights

## English - AWS source

1. Unified control: Manage access to databases, servers, Kubernetes, web applications, and MCP tools from one platform.
2. Policy and audit: Apply fine-grained permissions, approval workflows, activity monitoring, and audit trails.
3. Self-managed production: Run the platform in your AWS account with licensed capacity starting at 10 active users.
