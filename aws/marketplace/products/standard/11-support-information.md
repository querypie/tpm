# Support information

## 제출 상태

지원 이메일과 기술지원 웹사이트를 확정했습니다.

## English - AWS source

QueryPie ACP Standard Edition includes online documentation and community-based support through QueryPie Community Discussions.
Support is provided on a best-effort basis with no response-time SLA.
For technical support information, visit https://docs.querypie.com/support.
For AWS Marketplace subscription, support, billing, or refund requests, contact support@querypie.com.
AWS infrastructure charges are billed separately and are outside QueryPie's software refund policy.

## 한국어 리뷰용 번역

QueryPie ACP Standard Edition은 온라인 문서와 QueryPie Community Discussions를 통한 커뮤니티 기반 지원을 제공합니다.
지원은 최선 노력 기준으로 제공되며 응답 시간 SLA는 없습니다.
기술지원 정보는 https://docs.querypie.com/support 에서 확인할 수 있습니다.
AWS Marketplace 구독, 지원, 결제, 환불 요청은 support@querypie.com으로 연락해 주세요.
AWS 인프라 요금은 별도로 청구되며 QueryPie 소프트웨어 환불 정책의 대상이 아닙니다.
