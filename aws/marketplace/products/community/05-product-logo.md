# Product logo image URL

## AWS 입력값

`[PUBLIC_S3_LOGO_URL]/querypie-acp-community-edition.png`

## 제작 사양

- 투명 또는 흰 배경의 PNG를 사용합니다.
- 가로와 세로를 120~640px 범위로 맞춥니다.
- 1:1 또는 2:1 비율을 사용합니다.
- QueryPie 로고와 `Community Edition` 배지를 함께 표시해 검색 결과에서 에디션을 구분합니다.
- 공개 읽기가 가능한 Amazon S3 HTTPS URL을 사용합니다.

## 상태

로고 제작과 공개 S3 URL 확정이 필요합니다.
