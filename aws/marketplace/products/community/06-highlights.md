# Highlights

## English - AWS source

1. Unified control: Manage access to databases, servers, Kubernetes, web applications, and MCP tools from one platform.
2. Policy and audit: Apply fine-grained permissions, approval workflows, activity monitoring, and audit trails.
3. Community scale: Self-manage the platform for up to five active users with community-based support.

1. 통합 제어: 하나의 플랫폼에서 데이터베이스, 서버, Kubernetes, 웹 애플리케이션, MCP 도구의 접근을 관리합니다.
2. 정책과 감사: 세분화된 권한, 승인 워크플로, 활동 모니터링, 감사 추적을 적용합니다.
3. 커뮤니티 규모: 최대 5명의 활성 사용자를 위한 플랫폼을 직접 운영하고 커뮤니티 기반 지원을 이용합니다.
