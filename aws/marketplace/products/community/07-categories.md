# Product categories

## AWS 입력값

1. Infrastructure Software > Security
2. DevOps > Application Development

## 한국어 리뷰용 번역

1. 인프라 소프트웨어 > 보안
2. DevOps > 애플리케이션 개발

## 선정 근거

AWS Marketplace는 최대 3개 카테고리를 허용하지만 가장 관련성이 높은 분류만 선택하도록 권장합니다.
QueryPie ACP는 인프라 접근 제어와 감사 상품이므로 `Infrastructure Software > Security`가 가장 직접적인 기본 분류입니다.

`DevOps > Application Development`는 개발자와 개발팀을 위한 도구 중 애플리케이션 개발에 사용되는 상품을 대상으로 합니다.
Community Edition의 Web SQL Editor, Web Terminal, Kubernetes Web Client는 개발자가 브라우저에서 데이터베이스 쿼리, 서버 명령, Kubernetes 리소스 작업을 수행하도록 지원하므로 보조 분류로 적합합니다.

`Business Applications > Collaboration & Productivity`와 `Desktop applications > Productivity and Collaboration`은 추가하지 않습니다.
전자는 업무 협업용 상품, 후자는 데스크톱 애플리케이션을 위한 분류이므로 자체 운영형 보안 플랫폼인 QueryPie ACP의 주된 상품 유형과 일치하지 않습니다.
