## AWS Marketplace 공식 문서

- [Creating AMI-based products](https://docs.aws.amazon.com/marketplace/latest/userguide/ami-single-ami-products.html): Single AMI 생성 흐름, 가격 모델, 상품·배포·오퍼 입력 그룹
- [Updating AMI-based product information](https://docs.aws.amazon.com/marketplace/latest/userguide/single-ami-updating-product.html): 상품 소개 입력 필드 전체 목록
- [Work with seller products](https://docs.aws.amazon.com/marketplace/latest/developerguide/work-with-seller-products.html): Catalog API 필수 필드와 길이 제한
- [Providing metadata for AWS Marketplace products](https://docs.aws.amazon.com/marketplace/latest/userguide/categories-and-metadata.html): 제목, 설명, Highlights, 카테고리, 키워드 작성 지침
- [Managing versions for AMI-based products](https://docs.aws.amazon.com/marketplace/latest/userguide/single-ami-versions.html): Version, AMI, Endpoint, Security group 입력 항목
- [Translation and languages](https://docs.aws.amazon.com/marketplace/latest/userguide/translation.html): 영어 원문 제출, 기본 자동 번역 언어, Limited 상태 검수
- [Regions and countries](https://docs.aws.amazon.com/marketplace/latest/userguide/regions-and-countries.html): 배포 리전과 구매 국가의 차이
- [AMI-based product requirements](https://docs.aws.amazon.com/marketplace/latest/userguide/product-and-ami-policies.html): AMI 보안, 구조, 사용, 외부 의존성 정책
- [AMI product checklist](https://docs.aws.amazon.com/marketplace/latest/userguide/aws-marketplace-listing-checklist.html): 출시 전 제품과 이미지 점검표
- [Creating AMI and container product usage instructions](https://docs.aws.amazon.com/marketplace/latest/userguide/ami-container-product-usage-instructions.html): 사용, 상태 점검, 백업, 암호화, 업그레이드 지침 요구 사항
- [AMI product pricing](https://docs.aws.amazon.com/marketplace/latest/userguide/pricing-ami-products.html): Free, BYOL, Hourly, Usage, Contract 가격 모델
- [Submitting your product for publication](https://docs.aws.amazon.com/marketplace/latest/userguide/product-submission.html): 로고 규격, PLF, 스캔, 검토 기간, 최종 점검
- [Refunds and cancellations](https://docs.aws.amazon.com/marketplace/latest/userguide/refunds.html): 유료 상품 환불 정책과 연락 방법 요구 사항
- [Product categories](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-product-categories.html): `Security` 카테고리 정의
